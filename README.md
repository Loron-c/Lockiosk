# 车间生产平板锁屏 App（KioskLock）

自研 Android Kiosk 锁屏应用，替代 Fully Kiosk，专门针对联想小新平板（ZUI）的车间场景。

> 当前版本：**v1.1.0**
> - v1.0.1：修复 7 项导致构建失败/生产事故的问题
> - v1.0.2：新增**网址域名锁定**（对齐 Fully Kiosk 的 URL 白名单），修复返回键导致网页导航失效、边缘拦截误吞按钮点击
> - v1.0.3：新增**桌面接管**（对齐 Fully Kiosk：App 内一键设为默认桌面，彻底锁住 Home 键）
> - v1.1.0：**防忘密码**（可用平板系统锁屏密码兜底验证）、**崩溃安全模式**（连续崩溃自动进逃生页，防止默认桌面+崩溃循环变砖）、**方向锁定**（横屏/竖屏/跟随系统）、**细粒度开关**（音量键屏蔽、状态栏隐藏、锁屏密码兜底均可单独开关）、**免密配置区**（锁定未开启时进设置不需要密码）、管理手势统一为**左上双击→右下双击**、网址默认补 **https://**、云端构建**固定签名密钥**（不再每次换新签名导致升级必须卸载重装）

## 核心特性

| 功能 | 说明 |
|---|---|
| 全屏网页锁定 | WebView 全屏加载生产系统，无地址栏 |
| **网址域名锁定** | **只能停留在生产系统同域名内，点外部链接（百度/淘宝等）自动拦截并提示** |
| 多层跳转拦截 | 覆盖链接点击、JS `location.href`、表单提交、302 重定向、`window.open` / `target=_blank` 新窗口 |
| 屏蔽系统按键 | 菜单键、相机键拦截；**音量键屏蔽可开关** |
| 网页内导航保留 | 返回键在网页内可后退一页，到首页则停留（不会退出 App） |
| 拦截侧滑返回 | 屏幕左边缘「明确横向滑动」才拦，不影响靠边按钮点击 |
| 隐藏状态栏 | 沉浸式全屏，**可开关**（关闭后工人可看时间/电量） |
| 密码退出 | PIN 以 SHA-256 哈希存储，**输入框圆点隐藏，绝不明文显示** |
| **防忘密码** | **PIN 弹窗可选「忘记密码？用锁屏密码」，输平板系统锁屏密码即可放行（可开关）** |
| **免密配置区** | **锁定未开启时连点屏幕直接进设置，首次部署不用猜默认密码；勾选锁定后 PIN 才生效** |
| **崩溃安全模式** | **5 分钟内连续崩溃 2 次自动进原生逃生页（重试 / 凭密码进系统设置），防止「默认桌面 + 崩溃循环」变砖** |
| **方向锁定** | **跟随系统 / 固定横屏 / 固定竖屏，防止工人旋转平板弄乱页面排版** |
| 防误触手势 | 左上角双击 → 右下角双击（4 秒内），工人在网页中间正常操作永不触发 |
| 加载失败兜底 | 断网显示错误页 + 点击重试，不会白屏卡死 |
| 开机自启 | 断电重启后尝试自动恢复锁屏页 |
| 屏幕常亮 | 可配置 |
| 防卸载 | 可选激活设备管理器 |
| 批量配置 | SAF 文件选择器导出/导入，无权限要求，16 台 1 分钟一台 |
| 自动刷新 | 可设定时刷新，防页面挂起失效 |

## 「只能使用特定网页」是怎么实现的

对齐 Fully Kiosk 的机制，**四道防线**：

| 防线 | 拦截点 | 覆盖场景 |
|---|---|---|
| 1. `shouldOverrideUrlLoading` | 主框架导航 | 点 `<a>` 链接、JS `location.href`、表单提交 |
| 2. `onPageStarted` 兜底 | 页面开始加载时复查 | 服务器 302 重定向、JS 注入绕过 |
| 3. `onCreateWindow` 返回 false | 新窗口创建 | `<a target="_blank">`、`window.open()` |
| 4. 协议白名单 | scheme 判定 | `tel:` / `mailto:` / `intent:` / `file:` 等跳出协议 |

**放行规则**：`host` 与生产系统 host 完全相同，或是其子域（`erp.abc.com` 放行 `abc.com` 的子域跳转）。
**其他一律拦下**，页面停在原处，弹提示「已限制访问：xxx」。

> 注意：这只能限制 **WebView 内**的导航。工人按 Home 回桌面后打开其他浏览器，管不到 —— 那是平台限制，需靠「设为默认桌面」或「屏幕固定」或路由器白名单解决。

## 默认密码与忘记密码

**`202608`** —— 首次安装后请立刻在设置里改掉。

忘记密码有两条退路（按推荐顺序）：

1. **用平板系统锁屏密码兜底**（v1.1.0，默认开启）：PIN 弹窗点「忘记密码？用锁屏密码」→ 输入平板的锁屏密码 → 视同管理员放行。前提：平板在系统设置里配了锁屏密码。
2. 重装 APK：清除数据、恢复默认密码 `202608`。

> 建议 16 台平板统一设一个管理员才知道的系统锁屏密码，等于多了一把万能钥匙。

## 一、编译出 APK

### 方式 A：GitHub Actions 云端编译（推荐，本机无需任何环境）

⚠️ **先配签名密钥（v1.1.0 起必配，否则构建直接报错）**。原因见下：

> 签名 = APK 的「身份证」。Android 只允许**同身份证**的新包覆盖安装旧包。
> 如果每次构建都随机换身份证，16 台平板升级时会被系统拒绝安装，
> 只能卸载重装 → 网址、PIN、锁定配置全部丢光，重新配 16 台。
> 所以密钥必须**生成一次、固定不变**。

**配置步骤（3 分钟，一次永久）：**

1. 本机生成密钥（装了 JDK 或 Git 自带的 keytool 都行；没有的话用方式 B 的 Android Studio 终端）：
   ```
   keytool -genkeypair -v -keystore kiosk-release.jks -alias kiosk -keyalg RSA -keysize 2048 -validity 10000 -storepass kiosk2026 -keypass kiosk2026 -dname "CN=Kiosk, OU=IT, O=Yichi, L=Fujian, ST=Fujian, C=CN"
   ```
2. 转成 base64 文本（Windows PowerShell）：
   ```powershell
   [Convert]::ToBase64String([IO.File]::ReadAllBytes("kiosk-release.jks")) | Set-Clipboard
   ```
   （内容已复制到剪贴板）
3. GitHub 仓库 → **Settings → Secrets and variables → Actions → New repository secret**：
   - Name：`KEYSTORE_B64`
   - Secret：粘贴刚才复制的内容 → 保存

然后：

1. 新建仓库（Private 即可），把 `kiosk-app` 目录里**全部文件**上传（含 `.github` 隐藏目录；**不要上传 jks 文件本体**）
2. 仓库 **Actions** 标签 → 左侧 **Build Kiosk APK** → **Run workflow**
3. 等 3–5 分钟 → 点进运行记录 → 底部 **Artifacts** → 下载 `kiosk-apk.zip` → 解压得 `app-release.apk`

> 本地那个 `kiosk-release.jks` 文件**务必备份**（U 盘/网盘各一份），丢了等于丢身份证，以后所有升级都得重装。
> 若嫌 Secrets 麻烦：私有仓库可直接把 `kiosk-release.jks` 提交到仓库根目录，workflow 会自动识别（二选一即可）。
> 注意 `.gitignore` 默认忽略 jks，需用 `git add -f kiosk-release.jks` 强制提交，且仓库必须是 **Private**。

## 二、安装到平板（16 台批量）

已验证可行路径（二选一）：

1. **文件互传**：APK 发给平板 → 在互传 App 界面点安装
2. **文件管理器**：APK 放 `Download/` 或 U 盘根目录 → 文件管理器点安装

⚠️ **不要把 APK 放在 `Android/data/` 下** —— Android 10+ 分区存储会让文件管理器读不到完整文件，报 `packageinfo is null`。

## 三、首次配置（第 1 台）

1. 打开 App
2. **左上角双击 → 右下角双击** → **直接进设置，不需要密码**（锁定未开启时是免密配置区）
3. 配置：
   - **系统名称**：如「义齿生产系统」
   - **系统网址**：生产系统 URL（https）。裸地址会自动补 `https://`；若是纯 http 内网地址请手动写全 `http://`
   - **锁定访问域名**：勾上（默认已勾，这是「只能用特定网页」的开关）
   - **保持屏幕常亮**：按需（车间一般勾上）
   - **开机自动启动**：勾上
   - **细粒度锁定项**：屏蔽音量键（默认开）、隐藏状态栏（默认开）、锁屏密码兜底（默认开，建议先给平板设好锁屏密码）
   - **屏幕方向**：建议选「固定横屏」
   - ⚠️ **「启用 Kiosk 锁定」最后勾**：勾上并保存后，进设置就要开始输 PIN 了
5. 点 **修改管理员密码** → 改成你自己的密码（至少 4 位）
6. 点 **保存并返回** → 会自动弹「建议：设为默认桌面」→ 点 **现在设置** → 系统选择框里选 **车间生产系统** + **始终**
7. **验证清单**：
   - 按 Home 键 → 应该回到本应用（回不到系统桌面）✓
   - 页面里点一个外部链接 → 应弹「已限制访问」
   - 按音量键 → 无反应
   - 下拉状态栏 → 被隐藏
   - 网页内有下一层页面时按返回 → 能后退一页
   - 左上角双击 + 右下角双击 → 弹 PIN 框，输对进设置、输错报错
   - 重启平板 → 应自动进入本应用

## 四、批量部署剩下 15 台

1. 第 1 台配好 → 设置里 **导出配置文件（选择保存位置）** → 存到 Download 或 U 盘
2. 其他平板装好 APK → 进入设置 → **导入配置文件（选择文件）** → 指向那个 `kiosk-config.properties`
3. 配置和 PIN 哈希全部同步，一台 1 分钟

> 注意：导入会把 PIN 一并改成第 1 台设置的 PIN。所以**先在第 1 台把 PIN 改成你要的**，再导出。

## 七、已知限制与补强（重要）

### 限制 1：HOME 键无法屏蔽（所有普通 App 都做不到）——但可用「桌面接管」解决

Android 不允许普通应用拦截 HOME 键。**本 App 已内置 Fully Kiosk 同款的解决方案：**

> **设置 → 桌面接管 → 「设为默认桌面」按钮 → 系统弹选择框 → 选「车间生产系统」+「始终」**

设为默认桌面后：
- 工人按 Home 键 → **只会回到本应用**，回不到系统桌面，打不开其他应用
- 开机 → 系统直接进本应用（比自启动广播更可靠）
- 保存 Kiosk 锁定时，若未设置会**自动弹窗引导**（和 Fully Kiosk 一样的流程）
- 恢复方法：`设置 → 应用 → 默认应用 → 主屏幕应用` 改回原桌面；取消锁定时 App 也会提醒

备选方案（不想接管桌面时）：

| 方案 | 做法 | 效果 |
|---|---|---|
| 系统屏幕固定 | `设置 → 安全 → 更多安全设置 → 屏幕固定` → 钉住本 App | HOME/返回/多任务全部失效 |
| ADB 设备所有者 | 每台连电脑跑 `dpm set-device-owner` | 最彻底，但每台需删账户 + 电脑操作 |

### 限制 2：通知栏可能被边缘下拉唤出

沉浸式模式能隐藏状态栏，但个别 ROM 从屏幕顶部边缘下拉仍可能唤出快捷面板。补强同上（屏幕固定）。

### 限制 3：开机自启在部分 ROM 可能失效

Android 10+ 限制后台启动 Activity。已尽力兼容（BOOT_COMPLETED / QUICKBOOT / LOCKED_BOOT / MY_PACKAGE_REPLACED 四个广播 + startActivity），配合 ZUI 的「自启动 + 电池白名单」基本可用。若某台仍失效，把它设为默认桌面后可彻底解决。

### 强烈建议叠加：路由器防火墙白名单

16 台平板 MAC 绑 IP → 只放行生产系统服务器地址，其他全部拦截。
**即使工人退出锁屏、甚至关掉 App，平板也访问不了任何其他网站或下载任何东西。**

## 八、本地编译（方式 B）

1. 装 [Android Studio](https://developer.android.com/studio)（自带 JDK 17 + SDK）
2. 用 Android Studio 打开 `kiosk-app` 目录，等待 Gradle Sync
3. 生成签名密钥（在工程根目录执行，Windows CMD）：
   ```
   keytool -genkeypair -v -keystore kiosk-release.jks -alias kiosk -keyalg RSA -keysize 2048 -validity 10000 -storepass kiosk2026 -keypass kiosk2026 -dname "CN=Kiosk, OU=IT, O=Yichi, L=Fujian, ST=Fujian, C=CN"
   ```
   macOS / Linux / Git Bash 用 `\` 续行。
4. 菜单 **Build → Build Bundle(s) / APK(s) → Build APK(s)**
5. 产物：`app/build/outputs/apk/release/app-release.apk`

> 若不想把密码写在 build.gradle 里，可在根目录建 `keystore.properties`：
> ```
> storeFile=kiosk-release.jks
> storePassword=你的密码
> keyAlias=kiosk
> keyPassword=你的密码
> ```
> 该文件已在 `.gitignore` 中，不会误提交。

只想要能装的包、不急 release：直接 **Build → Build APK(s)** 用 debug 包也可以，功能完全一样。

## 九、排错速查

| 现象 | 原因 | 处理 |
|---|---|---|
| `Plugin [id: 'com.android.application'] was not found` | settings.gradle 缺仓库 | v1.0.1 已修；确认文件已上传 |
| `Keystore file not found` | 没生成 jks | 执行 keytool 命令，或先只打 debug 包 |
| 装到平板闪退 | 看 logcat | 开 USB 调试，`adb logcat \| grep yichi` |
| 开机不自启 | ROM 杀后台 | ZUI 三个开关；或设为默认桌面 |
| 按 Home 能回桌面 | 平台限制 | 设为默认桌面 / 屏幕固定 |
| 点生产系统里的链接被误拦 | 生产系统跨了域名 | 设置里关掉「锁定访问域名」，或让 IT 统一域名 |
| 靠屏幕边缘的按钮点不动 | 边缘拦截误吞 | v1.0.2 已修（只在明确横向滑动时拦） |
| 设置进不去 | 忘记 PIN | PIN 弹窗点「忘记密码？用锁屏密码」；平板没设锁屏密码则重装 APK（会清数据） |
| App 连续崩溃、重启也白屏 | 崩溃循环 | v1.1.0 自动进安全模式：选「重新尝试启动」或输密码进系统设置 |
| 工人转动平板页面排版乱 | 屏幕旋转 | 设置 → 屏幕方向 → 固定横屏 |
| 工人下拉看到通知 | 状态栏未隐藏 | 设置里确认「隐藏状态栏」已勾；通知内容要彻底没有需去系统通知管理逐个关 |

## 十、文件结构
